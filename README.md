### 👨🏻 About Me

- 🧠 CSE grad. Work across **full-stack, AI/CV, embedded systems, and robotics** — cybersecurity/API testing on the side.
- ⚙️ JavaScript by choice, everywhere — React, React Native, Node. TypeScript comes in wherever the platform calls for it.
- 🛠️ Currently building **StudentERP** — a role-based academic ERP across 6 user roles.
- 📡 Licensed Amateur Radio operator (**VU35DJ**) — active on EchoLink in whatever's left of my free time.

### 👨‍💻 Featured Projects:

- **[StudentERP](https://github.com/PUSKAR-DJ/StudentERP):** Role-based academic ERP — Expo/React Native, Supabase (Auth, Postgres, RLS, Edge Functions). This is the React-native rebuild of an earlier web ERP concept; the MVP proves out the idea, full web app launch planned next.
- **[FluidCalc](https://github.com/PUSKAR-DJ/FluidCalc):** My latest solo React Native build — a themeable standard/scientific calculator with animated UI, gradient themes, and calculation history. Initial APK release is out.
- **[Human Deception Detection](https://github.com/PUSKAR-DJ/Human_Deception_Detection):** Multimodal system combining computer vision and ML signals to detect deceptive behavior.
- **[ai-interview](https://github.com/PUSKAR-DJ/ai-interview):** AI-powered interview/assessment platform (MERN + Gemini 2.5 Flash for audio-native scoring) — built with a small team.
- **[Renu Sharma Foundation CRM](https://github.com/PUSKAR-DJ/frontend_sm):** CRM built for an NGO's operations.
- **[AlgoTrade](https://github.com/PUSKAR-DJ/AlgoTrade):** Algorithmic trading system/strategy engine.
- **[SNU-Robot](https://github.com/PUSKAR-DJ/SNU-Robot):** Robotics project planned on ROS fundamentals.
